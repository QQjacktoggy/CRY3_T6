M4／M6 的方向在 T+124–126 秒決策時凍結，只有 T+128–134.5 秒內觀察到的新鮮完整盤口可成為 paper quote。book 本身也必須來自 T+128 秒以後，年齡≤1秒、身分與費率一致，且能走完所選金額深度。沿用 0.01 股向下取整與份額扣費，不補造未成交訂單。

`regime_feature_service` 獨立蒐集 M4／M6，寫入 features DB 的 `t65_shadow_quotes`，不受 Live 已成交或 hold 路徑影響，且不會覆寫凍結決策。`UNOBSERVED_WINDOW` 表示未觀察到有效盤口，`NO_EXECUTABLE_WINDOW_QUOTE` 表示觀察過有效盤口但無足夠可執行報價；兩者分開統計。服務未运行時不補造歷史報價。

修正後會依 `c180_book_events` 的事件順序檢查當下仍新鮮的盤口，保留第一筆可執行報價，不會因較新的盤口覆寫 latest book 而漏掉較早報價。重啟時補結束過期的待觀測紀錄；report 也會依查詢時間辨識已過期紀錄。過期補結束不重播停機期間的盤口來假造觀測。

獨立 `c180_signal_runtime` 在入場窗口以外，每 20 秒輪詢一個待確認的 T6.5 shadow 市場，包含 Live 未成交或 loop 已結束的市場。結果另存 features DB 的 `t65_shadow_outcomes`；核對 topic、UP market ID、起訖時間與官方終結狀態後才接受 UP／DOWN／DRAW，缺失或錯誤結果保留待確認並重試，已確認結果跨重啟保留。使用既有唯讀 detail client 與共用 request-weight budget，不影響 Live 結算或風控資料。預設 features DB 位於 `--prediction-db` 同目錄的 `regime-target6/features.sqlite3`，可用 `--feature-db` 指定其他位置。

Live PnL／WR 只用實际成交及已核對的官方結算。Shadow 用官方 winner 或經市場身分核對的 observer 官方結果計算 quote 假設立即成交的費後 PnL；未知不補零，衝突不計。Shadow 報價參與率不是 fill rate，分母只含已過入場窗口且已登錄的市場；預先排程的未來市場不計。各 shadow 分支可能重疊，不能直接相加推定組合績效。

Live fill rate 的分子、分母都使用同一批已結束的正式登錄市場；有 BUY fill 的市場計入分子，待官方結算／redeem 不會使分母少算。未來排程與尚未結束的市場不計入。
